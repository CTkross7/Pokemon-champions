## Phase 0 완료 내역 (2026-07-12)
- 모노레포 구조: `/web`(Vite+React19+TS+Tailwind4), `/data`(파이프라인), `/docs`
- 레이아웃 셸: 반응형 헤더/모바일 내비, 다크모드(기본)·라이트모드 토글, 언어 토글(ko/en)
- i18n: i18next ko/en 리소스, zustand persist로 설정 저장
- 페이지: 홈(기능 카드), 소개, 준비중 플레이스홀더(도감/계산기/팀빌더)
- 데이터 파이프라인:
  - `data/scripts/fetch-ko-names.mjs`: PokéAPI CSV → 한글명 맵 (종 1,025 / 기술 901 / 특성 310 / 아이템 1,493 / 타입 / 성격)
  - `data/curated/regulation.json`: 게임 규칙(SP 66/스탯당 32/Lv50, VP, Reg M-B) — 출처 검증 등급 포함
  - `data/curated/roster.seed.json`: 등장 확인 포켓몬 시드 22종 (사용률 통계 교차 확인)
  - `data/scripts/validate.mjs`: 무결성 검증 (dex 참조·한글명·규칙 스키마) — ✅ 통과
- 법적 고지: 비공식 팬메이드 고지문 푸터 및 소개 페이지 반영
